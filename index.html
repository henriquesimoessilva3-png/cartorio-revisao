Você precisa de uma chave da Anthropic pra usar a ferramenta

Mesmo escolhendo "auto" no modelo, toda transcrição faz uma chamada à API que exige autenticação. O modo "auto" só significa que a ferramenta escolhe o modelo automaticamente (Haiku barato → Sonnet se difícil), não que funcione sem chave. Custo de teste com 14 PDFs do POC: ~US$ 0,30 (uns R$ 1,50).

  1. Crie conta em console.anthropic.com (precisa cartão de crédito)
  2. Defina um limite mensal primeiro em Settings → Limits (sugestão: US$ 10–20)
  3. Gere a chave em Settings → API Keys → Create Key e copie sk-ant-...
  4. Cole no campo azul do header acima ↑ — auto-salva ao pressionar Enter ou clicar fora

Configuração

A chave da API está no header azul no topo. Fica apenas no localStorage do seu navegador (nunca sobe pro servidor). Pegue em console.anthropic.com.

Vai no log de auditoria de cada aprovação.
